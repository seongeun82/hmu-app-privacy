교제나눔 도우미 개인정보처리방침

시행일: 2026년 11월 9일

교제나눔 도우미(이하 "앱")는 춘천 한마음교회 성도들이 교회 홈페이지(www.hmuchurch.com)를 폰에서 편하게 보도록 만든 앱입니다. 앱을 만든 사람은 별도의 서버를 운영하지 않으며, 사용자의 정보를 모으지 않습니다.

1. 앱을 만든 사람이 모으는 정보

없습니다. 앱은 만든 사람에게 어떤 정보도 보내지 않습니다. 광고, 사용 통계, 오류 보고 도구도 넣지 않았습니다.

2. 로그인

  • 로그인은 앱 안에 열리는 교회 홈페이지 로그인 화면에서 합니다. 아이디와 비밀번호는 교회 홈페이지로 바로 전달되며, 앱은 비밀번호를 저장하지 않습니다.
  • 로그인 상태를 유지하기 위한 교회 홈페이지의 쿠키는 사용자의 폰 안에만 저장됩니다.

3. 앱이 연결하는 곳

  • 교회 홈페이지(www.hmuchurch.com): 글·댓글 보기, 사용자가 직접 쓴 댓글과 글의 등록·임시 저장, 첨부파일 받기. 이 내용은 교회 홈페이지의 운영 방침에 따라 처리됩니다.
  • YouTube·Vimeo: 간증 영상을 재생하고 영상 제목을 가져올 때만 연결합니다. 이때 각 서비스의 개인정보처리방침이 적용됩니다.

위 외의 다른 곳에는 연결하지 않습니다. 모든 연결은 암호화(HTTPS)됩니다.

4. 폰에 저장되는 정보

  • 로그인 쿠키, 글씨 크기 같은 설정, 쓰는 중인 글(작성 중 자동 저장), 위젯에 보여 줄 최근 글 목록, 사용자가 받은 첨부파일(다운로드 폴더)
  • 앱을 지우면 첨부파일을 제외한 정보는 모두 지워집니다. 폰 백업에도 포함되지 않습니다.

5. 정보 삭제

  • 폰에 저장된 정보: 앱을 지우거나, 폰 설정 → 애플리케이션 → 교제나눔 도우미 → 저장공간 → 데이터 삭제
  • 교회 홈페이지에 등록한 글·댓글·계정: 앱이나 교회 홈페이지에서 직접 지우거나 교회 홈페이지 관리자에게 요청하세요.

6. 아동

앱은 교회 홈페이지 회원을 위한 것으로, 아동을 대상으로 하지 않습니다.
